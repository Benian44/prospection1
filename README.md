# IBS SARL - Site Web Professionnel

Ce projet est un site vitrine professionnel pour IBS SARL (Immobiliers Bâtiments et Services SARL), une entreprise ivoirienne spécialisée dans la construction, rénovation immobilière, menuiserie aluminium, plafonds staff et gestion immobilière.

## Technologies utilisées

- Astro.js - Framework web performant
- Tailwind CSS - Framework CSS utilitaire
- TypeScript - Typage statique pour JavaScript
- AOS - Animation à l'apparition

## Fonctionnalités

- Site 100% responsive (mobile, tablette, desktop)
- Formulaire de demande de devis avec envoi via WhatsApp
- Galerie photo (portfolio)
- Intégration Google Maps
- Optimisé SEO

## Structure du projet

- `/src/pages` - Pages du site
- `/src/components` - Composants réutilisables
- `/src/layouts` - Layouts du site
- `/public` - Ressources statiques

## Scripts

- `npm run dev` - Démarre le serveur de développement
- `npm run build` - Génère le site en production
- `npm run preview` - Prévisualise le site de production en local

## Déploiement

Pour déployer le site en production, exécutez :

```bash
npm run build
```

Les fichiers générés se trouvent dans le répertoire `dist/`.
